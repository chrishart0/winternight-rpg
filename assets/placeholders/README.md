# Phase 0 placeholder provenance

All Phase 0 game images are generated deterministically by `winternight_gen.asset_pipeline` from geometric shapes. The bitmap font atlas uses Pillow's bundled default font and therefore remains covered by Pillow's permissive license; no system font file is copied into the project.

No image model, Fire Emblem asset, Wheel of Time asset, or LT sample-project resource is used.
