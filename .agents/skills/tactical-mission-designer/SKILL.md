# Tactical Mission Designer

Start from approved beat IDs and narrative constraints. Define objective, map state, units, groups, reinforcements, tutorial or tactical lessons, failure conditions, scripted outcomes, and expected turns/minutes.

Reject a design that relies on deliberate player failure for a required story outcome. Reject repetitive `defeat_all` objectives when a story-shaped escape, defense, rescue, interaction, or survival objective is viable. Keep story-critical outcomes deterministic and label gameplay inventions.

Read [references/mission-review.md](references/mission-review.md) for a mission review. This skill is inactive in Phase 0 except for its original one-room engine fixture.
