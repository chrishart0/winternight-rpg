# Visual Asset Director

Check the phase gate before any generation. In Phase 0, only legally clean programmatic graybox placeholders are allowed.

For approved later assets, start from the visual bible and identity references. Record asset ID, subject/location ID, prompt, reference IDs, provider/model, seed when available, source/output hashes, processing version, approval, and license/provenance note. Treat AI output as source art; use deterministic crop, reduction, quantization, sheet assembly, and engine-format validation.

Read [references/asset-contract.md](references/asset-contract.md) before changing the asset manifest or processing pipeline.
