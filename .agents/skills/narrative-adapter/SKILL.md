# Narrative Adapter

Work only from notes the user has authorized. Never commit private notes or substantial source excerpts. Produce concise facts, scene intent, constraints, and newly written paraphrase.

Give every beat a stable ID and one status: `direct`, `inferred`, `gameplay_invention`, or `altered`. Preserve chronology and the agreed story boundary. Record uncertainty instead of inventing a direct fact.

Read [references/beat-contract.md](references/beat-contract.md) before adding or changing narrative data. This skill is inactive in Phase 0 except for maintaining its own instructions.
